# AI Book

A multi-user library you can ask questions of. Sign in with Google, keep sources inside an organization, and chat over the indexed text with Grok.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Copy `.env.example` to `.env.local` and replace the placeholder values before signing in.

Default limits per library: 50 files, 20 websites, 100 notes, and 10,000 chunks. Admins can change them in library settings.
